An Android screen plus a small backend on your computer, for trying BCA's sandbox balance inquiry.

Sandbox only. Not a banking app. This page has no sign-in and takes no credentials. The bank integration has not been tested against BCA, and it is not a security audit. Do not use real banking credentials.

How it fits together

Phone appUSB + adb reverse, 127.0.0.1:8787 Node backend on your computerHTTPS sandbox.bca.co.id
  • The app has a token field and two buttons: check the backend, and test the BCA balance. It shows the JSON it gets back and stores nothing.
  • The backend listens on 127.0.0.1 only, needs your tester token, and allows only GET /health and GET /balance. There is no transfer or payment route.
  • BCA credentials and the private key stay in files on your computer, never in the app or the repository.

Get started

The README has the step-by-step guide for sandbox credentials, including which steps are unverified.

cd backend
cp env-template.txt .env
openssl rand -hex 32   # TESTER_TOKEN
npm run check
npm start
adb reverse tcp:8787 tcp:8787
